Control Hub 0.0.001

Windows x64 installation guide · development build

Stream Deck → PowerPoint and OBS is the first priority. AndroidRemote and the other device integrations are only planned. This installation package does not establish acceptance for live operation.

1. Install

  1. Open ControlHub-0.0.001-win-x64-Setup.exe and select English. It installs for your Windows user and includes a standard uninstaller.
  2. .NET is included. PowerPoint desktop, OBS Studio and Stream Deck 7.4 or later must already be installed. This package targets Windows x64; Windows 11 is recommended. Windows 10 requires at least build 17763; support for your specific Windows edition must be checked separately.
  3. Open Control Hub from the Start menu. Select Dansk or English. No terminal window is needed.

The package is not code-signed and Windows may display an unknown publisher warning. It installs no service, changes no firewall rules and does not start automatically at login.

2. Connect OBS and start Control Hub

  1. Enable OBS' WebSocket server in OBS and check its port and password. Use the WebSocket password, not your streaming key.
  2. Enter the address, usually ws://127.0.0.1:4455, and password in Control Hub. Click Save settings.
  3. Click Start Control Hub. Status reports PowerPoint and OBS connectivity separately. Check connection only reads status.

3. Install the Stream Deck keys

  1. Click Install Stream Deck plugin in Control Hub and complete Stream Deck's installation dialog. Alternatively, double-click the included dk.thebonden.controlhub.streamDeckPlugin.
  2. If you already have the manual development installation, let Stream Deck handle replacement. If it rejects the same version, remove only the Control Hub plugin in Stream Deck and reinstall the package. Note your key settings first; changes may require reconfiguration. Fully exit and restart Stream Deck if the group is missing.
  3. Drag Status, Next slide, Previous slide and Switch scene from the Control Hub group onto a test profile.
  4. Click Copy connection key in Control Hub. Paste it into each Stream Deck key's token field. Select a language, enter any arguments and click Save.
  5. Click Test connection in the key's settings. Enter the exact names of OBS scenes and audio inputs.

4. Try a test show

Manually start exactly one PowerPoint slideshow. Control Hub never modifies or saves presentation files. Test next/previous, black screen, resume and OBS scene selection, including while another app has focus. Start streaming is a real live operation; use it only for an agreed test destination or an intended broadcast. Installer testing does not start recording or streaming.

Stopping, updating and uninstalling

Keep the control window open while using Control Hub. Stop Control Hub or closing the window stops only the host started by that window. PowerPoint and OBS remain open. Stop Control Hub before changing OBS settings and before upgrading. Uninstall via Windows Installed apps. Remove the Stream Deck plugin separately in Stream Deck.

Settings and a random persistent connection key are encrypted with Windows DPAPI for your user in %LOCALAPPDATA%\ControlHub\settings.dat. They are preserved on uninstall. Stream Deck stores its own copy in key settings: do not share profiles containing the key or paste it into chat or GitHub. Copying puts the key on the clipboard; overwrite it afterwards by copying ordinary text.

Troubleshooting

  • Port 5187 in use: stop an earlier terminal-based Control Hub before starting the control window's host.
  • PowerPoint unavailable: start one slideshow, close dialogs, and run the apps as the same user at the same privilege level.
  • OBS unavailable: check the local WebSocket server, port and password.
  • Settings cannot be read: move settings.dat to a safe local backup and restart. You must then enter the new key on all buttons. The app does not automatically overwrite unreadable settings.

The version is 0.0.001. The installer creates no release or tag. Every .100 boundary and 0.1.000 require owner approval.
