Control Hub 0.0.001

Installationsvejledning til Windows x64 · udviklingsversion

Stream Deck → PowerPoint og OBS er første prioritet. AndroidRemote og de øvrige enhedsintegrationer er endnu kun forberedt. Installationspakken er ikke en godkendelse af praktisk afvikling.

1. Installér

  1. Åbn ControlHub-0.0.001-win-x64-Setup.exe, og vælg Dansk. Programmet installeres for din Windows-bruger og har en almindelig afinstalleringsfunktion.
  2. .NET er inkluderet. PowerPoint desktop, OBS Studio og Stream Deck 7.4 eller nyere skal allerede være installeret. Pakken er til Windows x64; Windows 11 anbefales. Windows 10 kræver mindst build 17763, og understøttelsen af din konkrete Windows-udgave skal kontrolleres særskilt.
  3. Åbn Control Hub fra Start-menuen. Vælg Dansk eller English. Der kræves ikke et terminalvindue.

Pakken er ikke kodesigneret og kan derfor give en Windows-advarsel om ukendt udgiver. Den installerer ingen service, ændrer ingen firewallregel og starter ikke automatisk ved login.

2. Tilslut OBS og start Control Hub

  1. Aktivér OBS' WebSocket-server i OBS, og aflæs port og adgangskode. Brug WebSocket-adgangskoden, ikke streamingnøglen.
  2. Indtast adressen, normalt ws://127.0.0.1:4455, og adgangskoden i Control Hub. Tryk Gem indstillinger.
  3. Tryk Start Control Hub. Status viser separat, om PowerPoint og OBS svarer. Kontrollér forbindelse læser kun status.

3. Installér Stream Deck-knapperne

  1. Tryk Installér Stream Deck-plugin i Control Hub, og gennemfør Stream Decks installationsdialog. Du kan også dobbeltklikke på den medfølgende dk.thebonden.controlhub.streamDeckPlugin.
  2. Har du allerede den manuelle udviklingsinstallation, så lad Stream Deck håndtere udskiftningen. Hvis samme version afvises, fjern kun Control Hub-pluginet i Stream Deck og installér pakken igen. Notér først knapindstillinger; ændringer kan kræve ny opsætning. Afslut og genstart Stream Deck helt, hvis gruppen mangler.
  3. Træk Status, Næste slide, Forrige slide og Skift scene fra gruppen Control Hub til en testprofil.
  4. Tryk Kopiér forbindelsesnøgle i Control Hub. Indsæt nøglen i tokenfeltet på hver Stream Deck-knap. Vælg sprog, angiv eventuelle argumenter, og tryk Gem.
  5. Tryk Test forbindelse i knappens indstillinger. Angiv OBS-scener og lydkilder med deres præcise navne.

4. Afprøv på et testshow

Start selv præcis ét PowerPoint-slideshow. Control Hub ændrer eller gemmer aldrig præsentationsfiler. Afprøv næste/forrige, sort skærm, genoptag og OBS-scenevalg, også mens et andet program har fokus. Start udsendelse er en reel livehandling; brug den kun til en aftalt testdestination eller en tilsigtet udsendelse. Installerens test starter ingen optagelse eller udsendelse.

Stop, opdatering og afinstallation

Hold kontrolvinduet åbent under brug. Stop Control Hub eller lukning af vinduet stopper kun den host, vinduet har startet. PowerPoint og OBS forbliver åbne. Stop Control Hub før ændring af OBS-indstillinger og før opdatering. Afinstallér via Windows' Installerede apps. Stream Deck-pluginet fjernes separat i Stream Deck.

Indstillinger og en tilfældig, vedvarende forbindelsesnøgle gemmes krypteret med Windows DPAPI for din bruger i %LOCALAPPDATA%\ControlHub\settings.dat. De bevares ved afinstallation. Stream Deck gemmer sin egen kopi i knappens indstillinger: del ikke profiler med nøglen, og indsæt den ikke i chat eller GitHub. Kopiering placerer nøglen på udklipsholderen; overskriv den bagefter ved at kopiere almindelig tekst.

Hvis forbindelsen fejler

  • Port 5187 optaget: stop en tidligere terminalbaseret Control Hub, før du starter kontrolvinduets host.
  • PowerPoint utilgængelig: start ét slideshow, luk dialoger, og kør programmerne som samme bruger og på samme rettighedsniveau.
  • OBS utilgængelig: kontrollér lokal WebSocket-server, port og adgangskode.
  • Indstillinger kan ikke læses: flyt settings.dat til en sikker lokal backup, og start igen. En ny nøgle skal derefter indtastes på alle knapper. Programmet overskriver ikke en ulæselig konfiguration automatisk.

Versionen er 0.0.001. Ingen release eller tag oprettes af installeren. Hver .100-grænse og 0.1.000 kræver ejerens godkendelse.
