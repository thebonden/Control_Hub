# Projektregler / Project rules

- Dansk: Kommunikér med ejeren på dansk. Dokumentation og brugervendte tekster skal være på dansk og engelsk.
- English: Communicate with the owner in Danish. Documentation and user-facing text must be Danish and English.
- Dansk: Prioritér Stream Deck sammen med PowerPoint og OBS Studio; derefter AndroidRemote.
- English: Prioritize Stream Deck with PowerPoint and OBS Studio, followed by AndroidRemote.
- Dansk: Alle pluginimplementationer og aktiver under Plugins/. Ingen ændring af præsentationsfiler eller fokusafhængige genveje.
- English: All plugin implementations and assets belong under Plugins/. Never modify presentation files or use focus-dependent shortcuts.
- Dansk: Brug arbejdsbranch og PR mod main. Byg og test. Rapportér faktisk implementering og resterende hardwaretest.
- English: Use a working branch and PR to main. Build and test. Report actual implementation and remaining hardware tests.
- Dansk: Ingen release eller tag uden ejerens godkendelse. Hver .100-grænse og skiftet til 0.1.000 kræver særskilt godkendelse. Følg docs/versioning.md.
- English: No release or tag without owner approval. Each .100 boundary and transition to 0.1.000 needs separate approval. Follow docs/versioning.md.
