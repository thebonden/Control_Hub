# StreamDeck

## Dansk
Implementeret plugin med 12 handlinger og officiel `.streamDeckPlugin`-installationspakke. Indlæsning er verificeret i Stream Deck; samlet praktisk PowerPoint/OBS-accept afventer. Windows-installationspakken indeholder pluginpakken.

Se [installation](../../docs/setup.da.md), [arkitektur](../../docs/project.da.md), [protokol](../../docs/protocol.da.md) og [testplan](../../docs/testing.da.md).
