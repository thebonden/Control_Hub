# Android Live / Android Live

## Dansk

Status i 0.0.001: **planlagt, ikke implementeret**. Plugin-id: `android-live`. Hosten registrerer en fælles `PlannedPlugin` med tom handlingsliste og `not_implemented`-status. Der er ingen driver, transport eller app i denne mappe endnu.

Afklar om integrationen omfatter kamera, status eller styring. Fastlæg transport, parring og adgang. Denne integration er adskilt fra AndroidRemote.

Accept kræver en dokumenteret protokol, fejl- og forbindelsestests, hardwaretest og danske/engelske brugertekster. Implementationskode skal placeres i denne mappe under `Plugins/`.

## English

0.0.001 status: **planned, not implemented**. Plugin ID: `android-live`. The host registers a shared `PlannedPlugin` with an empty action list and `not_implemented` status. No driver, transport or app exists in this directory yet.

Establish whether the integration covers a camera, status or control. Define transport, pairing and access. This integration is separate from AndroidRemote.

Acceptance requires a documented protocol, error and connection tests, hardware testing and Danish/English user text. Implementation code must be placed in this directory under `Plugins/`.
