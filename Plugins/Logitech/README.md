## English

0.0.001 status: **planned, not implemented**. Plugin ID: `logitech`. The host registers a shared `PlannedPlugin` with an empty action list and `not_implemented` status. No driver, transport or app exists in this directory yet.

Establish the exact model and documented SDK/HID protocol. Map device events to named commands; do not use global keyboard shortcuts.

Acceptance requires a documented protocol, error and connection tests, hardware testing and Danish/English user text. Implementation code must be placed in this directory under `Plugins/`.
